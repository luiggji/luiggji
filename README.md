### Como eu trabalho

`PRD` → `Backlog` → `Issue` → `Branch` → `Pull Request` → `CI` → `Code review` → `Release`

- **Git Flow** com uma branch por issue, merge via pull request e releases versionadas (SemVer).
- **CI em toda PR**: lint, typecheck, testes, build e varredura de segurança.
- **Clean Architecture** por contexto de negócio, decisões registradas em ADRs.
